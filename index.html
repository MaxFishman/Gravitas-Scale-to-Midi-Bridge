Questions

Good to know.

Which scales actually work?

The DYMO S100 and the U.S. Solid Precision Balance are certified out of the box. Beyond those, generic HID and serial profiles auto‑extract the weight from most USB scales — if it reports over USB HID or prints ASCII over a serial port, it almost certainly works.

Do I need to install drivers or write any code?

No. GRAVITAS runs entirely in Chrome or Edge using the browser's hardware APIs. The only optional component is the OSC bridge, which is a single Node command if you want parameter‑addressed OSC control.

Does it work with my DAW, not just Ableton?

Yes. GRAVITAS sends standard MIDI Control Change over your OS MIDI bus, so any DAW with MIDI Learn — Logic, Live, Bitwig, FL Studio, Reaper — can map it. Ableton users get the extra option of deep OSC control via AbletonOSC.

Why Chrome or Edge only?

WebHID, Web Serial, and Web MIDI are only exposed by Chromium‑based browsers today. Firefox and Safari don't yet provide the hardware access GRAVITAS needs to talk to your scale.

Where does my data go?

Nowhere. Everything runs locally on your machine — scale to browser to MIDI bus. There's no account, no telemetry, and no cloud dependency.
